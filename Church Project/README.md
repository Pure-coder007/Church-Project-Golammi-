# Gateway of Life and Miracle Ministries International - Golammi Worship Center Website

A comprehensive church website for Gateway of Life and Miracle Ministries International (Golammi Worship Center), a prophetic ministry dedicated to spiritual reconstruction and miracle ministry. This project provides a full-featured web presence with ministry information, event management, media streaming, donation capabilities, and community engagement tools.

## 🌟 Project Overview

**Gateway of Life and Miracle Ministries International (GWC)** is a prophetic ministry website designed to:
- Share the ministry's mission, vision, and beliefs
- Provide information about church services and events
- Enable online giving and donations
- Stream live services and radio broadcasts
- Offer prophetic training through the School of Prophets
- Facilitate prayer requests and community engagement
- Showcase sermons, blogs, and media content

## 🚀 Installation & Setup

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)
- Web server (Apache/Nginx) for production
- MySQL/PostgreSQL database (for production)

### Local Development Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd Church Project
   ```

2. **Create virtual environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up environment variables**
   Create a `.env` file:
   ```env
   FLASK_APP=app.py
   FLASK_ENV=development
   SECRET_KEY=your-secret-key
   DATABASE_URL=sqlite:///church.db
   MAIL_SERVER=smtp.gmail.com
   MAIL_PORT=587
   MAIL_USE_TLS=True
   MAIL_USERNAME=your-email@gmail.com
   MAIL_PASSWORD=your-email-password
   ```

5. **Initialize database**
   ```bash
   flask db init
   flask db migrate -m "Initial migration"
   flask db upgrade
   ```

6. **Run the development server**
   ```bash
   flask run
   ```

7. **Open in browser**
   Navigate to `http://127.0.0.1:5000`

### Production Deployment

1. **Set production environment variables**
   ```env
   FLASK_ENV=production
   ```

2. **Use a production WSGI server**
   ```bash
   pip install gunicorn
   gunicorn -w 4 -b 0.0.0.0:8000 app:app
   ```

3. **Configure web server** (Nginx example)
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           proxy_pass http://127.0.0.1:8000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
       
       location /static {
           alias /path/to/Church Project/assets;
       }
   }
   ```
